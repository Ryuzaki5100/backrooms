# Archived: noclip orchestration

This directory holds the retired "noclip" multi-agent orchestration: the
`noclip` CLI config, the OpenCode agent roles, the `dispatch` command, and the
original `AGENTS-WORKFLOW.md` procedure.

It was retired by ADR 0032 A3 on 2026-11-27. Files were moved here with
`git mv`, not deleted, so their history is preserved.

The replacement is **prodev**, the only orchestration system for this
repository. See `AGENTS.md` at the repo root (section "Multi-agent workflow").

Nothing in this directory is loaded or executed. Do not restore it into
`.opencode/` or `.noclip` without a new ADR.
